# Tower Defense 🗼

スマホのブラウザで遊べる、シンプルなタワーディフェンスゲームです。
**TypeScript + Vite + HTML5 Canvas** 製で、インストール不要・URL を開くだけで遊べます。

タッチ操作前提のモバイルファースト設計（縦持ち 9:16）。仮想解像度 720×1280 で作り、
どんな画面比でもレターボックスで自動フィットします。

---

## 遊び方

- 下部の**パレットでタワー種別を選び**、**空きマスをタップ**して設置
- **各タワーは 1 種類につき 1 基まで**（設置済みの種別は「設置済」表示）
- タワーは射程内の敵を自動で狙って攻撃します
- **設置済みのタワーをタップ**すると**強化／スキル**パネルが開きます
- 敵を倒すとゴールド獲得、貯めて強化・防衛
- 敵が経路の終点に到達すると**ライフが減少**、0 でゲームオーバー
- メインボタンでウェーブ開始（合計 10 ウェーブ）。**ウェーブ終了後は 5 秒で自動的に次が始まります**
- **ウェーブ中でもメインボタンで次のウェーブを「早出し」**できます（一気に攻め込まれるので上級者向け）
- 右下の「**ステータス**」ボタンで全タワー・全敵の数値一覧を確認できます（表示中は一時停止）
- 全ウェーブ防衛でクリア。ゲームオーバー／クリア後は**タップでリスタート**

> ヒント: ウェーブの合間だけでなく、戦闘中でもゴールドがあれば強化できます。

### タワー 5 種（Lv で挙動が進化）

| タワー | コスト | 進化（Lv1 → Lv2 → Lv3） |
| --- | --- | --- |
| 🟢 Matenrou | 50G | ガン → **マシンガン**（連射UP）→ **ファイア**（範囲攻撃） |
| 🟠 Sae | 90G | **日本刀の斬撃**：近接・短射程だが**射程内は範囲攻撃**。Lv で射程と威力UP |
| 🔵 Eita | 70G | **減速**。Lv3 で**範囲攻撃＋範囲減速**になる |
| 🟣 Tsukahara | 110G | **長射程・高威力**の狙撃（連射は遅い） |
| 🩷 ayase | 80G | 攻撃しない補助塔。**射程内の味方タワーの連射速度を上げる**（範囲は薄いオーラ、バフ中の塔には▲印） |

各タワーは **Lv.3 まで強化**でき、レベルごとに性能や特殊効果が変化します（数値は「ステータス」一覧で確認可）。

### タワースキル（旧・売却ボタン → 1 ステージ 1 回だけ）

設置済みタワーの右下ボタンは**スキル**になっています。各タワー固有で、**1 プレイ（リスタートまで）に 1 回だけ**使えます。

| タワー | スキル | 効果 |
| --- | --- | --- |
| Matenrou | 全体攻撃 | 画面全体に大ダメージ。使用後 **3 秒**自身が攻撃不能 |
| Eita | 全体攻撃＋減速 | 画面全体に攻撃しつつ全体を減速。使用後 **10 秒**攻撃不能 |
| Sae | 高速斬撃 | **3 秒間 連射×3**、その後 **10 秒**攻撃不能 |
| Tsukahara | 移動 | **別の空きマスへ移動**できる（候補マスがハイライト） |
| ayase | 攻撃力UP | **10 秒間**、範囲内の味方の**攻撃力を 1.2 倍** |

### 敵 5 種

| 敵 | 特徴 |
| --- | --- |
| ノーマル | 標準的な性能 |
| ファスト | 低 HP・高速 |
| タンク | 高 HP・低速・**装甲**（小ダメージを軽減） |
| スウォーム | 小型・低 HP の群れ |
| ボス | 超高 HP・高報酬（最終ウェーブ） |

ウェーブが進むと敵が混在し、基準 HP・速度も上がっていきます。

### ステージ（全 3 ステージ）

ステージごとに**経路（マップ）・ウェーブ構成・難易度**が変わります。クリアすると次のステージへ、
**全 3 ステージ制覇でゲームクリア**です。

| ステージ | 名前 | 開始ゴールド / ライフ / ウェーブ数 | 特徴 |
| --- | --- | --- | --- |
| STAGE 1 | みどりの小道 | 150 / 20 / 6 | やさしい蛇行。基本を覚える |
| STAGE 2 | まわり道 | 190 / 20 / 7 | 左右に大きく折り返す。HP↑ |
| STAGE 3 | 九十九折り | 240 / 22 / 8 | 長いジグザグ・ボス複数。最難関 |

- 各ステージは**盤面リセット**（タワーは建て直し、開始ゴールドはステージごとに増加）
- スキルの「1 ステージ 1 回」もステージ切り替えでリセット
- **ゲームオーバーはそのステージを再挑戦**（最初には戻りません）
- ステージ／ウェーブ構成は `src/game/stages.ts`、難易度は `src/game/waves.ts` で調整できます

## 必要環境

- Node.js 20 以上（推奨 22）

## セットアップ

```bash
npm install
```

## 開発サーバーを起動

```bash
npm run dev
```

表示された URL（例 `http://localhost:5173`）をブラウザで開きます。

### 📱 スマホ実機で試す（同じ Wi-Fi）

`vite.config.ts` で `server.host` を有効にしてあるので、`npm run dev` 実行時に
`Network:` として LAN の URL（例 `http://192.168.x.x:5173`）が表示されます。
スマホを同じ Wi-Fi に接続し、その URL を開けば実機で遊べます。

## ビルド / プレビュー

```bash
npm run build     # 型チェック + 本番ビルド（dist/ を生成）
npm run preview   # ビルド結果をローカルで確認
```

## テスト / 型チェック

```bash
npm test          # vitest（コアロジックの単体・統合テスト）
npm run typecheck # tsc による型チェック
```

## ディレクトリ構成

```
.
├── index.html               # エントリ HTML
├── src/
│   ├── main.ts              # 起動・リサイズ・入力・描画ループ
│   ├── style.css            # 全画面・タッチ最適化のスタイル
│   └── game/
│       ├── constants.ts     # 画面サイズ・グリッド・バランス・配色
│       ├── types.ts         # 共有型
│       ├── towerTypes.ts    # タワー種別の定義（ステータス・強化計算）
│       ├── enemyTypes.ts    # 敵種別の定義（HP/速度倍率・装甲・見た目）
│       ├── stages.ts        # 3 ステージの経路・ウェーブ・開始値の定義
│       ├── waves.ts         # ウェーブ型とステージ別の基準ステータス（難易度）
│       ├── Viewport.ts      # 仮想解像度⇄実画面のスケール変換・座標変換
│       ├── Path.ts          # 敵の経路（曲がり角）と設置可否判定
│       ├── Enemy.ts         # 敵（経路移動・HP・装甲・スロー）
│       ├── Tower.ts         # タワー（索敵・発射・レベル）
│       ├── Projectile.ts    # 弾（追尾・命中・範囲・スロー付与）
│       ├── Game.ts          # 状態・更新・描画・UI（パレット/強化売却）
│       └── *.test.ts        # 各種テスト
├── .github/workflows/deploy.yml   # GitHub Pages へ自動デプロイ
└── .claude/                 # Claude Code on the web 用のセッション設定
```

設計の要点:

- **更新（`update`）と描画（`render`）を分離**。ロジックは DOM 非依存なので Node 上の
  テストでウェーブ進行まで丸ごと検証できます。
- 座標はすべて**仮想座標系（720×1280）**で考え、実画面へのスケールは `Viewport` に集約。
- 入力は `pointerdown` で統一（マウス・タッチ・ペン共通）。

---

設計はデータ駆動です。タワー・敵・ウェーブは定義ファイルを編集するだけで増やせます。

## 拡張のヒント

- **タワーの種類を増やす**: `towerTypes.ts` の `TOWER_TYPES` に 1 エントリ足し、
  `TOWER_TYPE_LIST` に並べるだけでパレットに出ます（`splashRadius` / `slowFactor` を
  付けると範囲・減速タワーになります）。
- **敵の種類を増やす**: `enemyTypes.ts` の `ENEMY_TYPES` に追加（HP/速度倍率・装甲・
  半径・色）。`waves.ts` の各ウェーブで使えます。
- **ウェーブを編集**: `waves.ts` の `WAVES`（どの敵を何体・間隔）と `enemyBaseStats()`
  （ウェーブごとの基準 HP・速度）を調整。
- **経路を変える**: `Path.ts` の `WAYPOINTS_GRID` を編集（連続する点は必ず縦か横）。
- **バランス調整**: `constants.ts` の `START_LIVES` / `START_MONEY` / `MAX_TOWER_LEVEL`
  / `SELL_REFUND_RATE`、各定義ファイルのステータス。

> 開発時は URL に `?debug` を付けるとブラウザのコンソールから `window.__game` で
> 状態を参照できます（通常アクセスでは無効）。

## 📱 GitHub Pages で公開してスマホから遊ぶ

`main` ブランチへの push で自動デプロイされます（`.github/workflows/deploy.yml`）。

初回のみリポジトリで設定が必要です:

1. リポジトリの **Settings → Pages**
2. **Build and deployment → Source** を **「GitHub Actions」** に変更
3. `main` に push（または Actions タブから手動実行）

公開後の URL は `https://<ユーザー名>.github.io/td/` です。スマホのブラウザでこの URL を
開けば、インストール不要でそのまま遊べます。

## Claude Code on the web について

`.claude/` に、Web セッション開始時に依存関係を自動インストールする **SessionStart
フック**を用意しています。これにより、Web 上のセッションでも `npm test` /
`npm run typecheck` / `npm run build` がすぐ実行できます。
この設定を**デフォルトブランチへマージすると、以降のすべての Web セッションで有効**になります。
